# 采访视频数据管理与检索系统 - 技术方案文档

## 1. 项目概述
本软件专为采访工作者设计，旨在解决海量素材管理、无时码器声画对齐困难及后期检索效率低下的痛点。系统集成了专业级非线性编辑（NLE）时间轴与全局字幕数据库，通过内容匹配实现智能对齐与跨工程检索。

## 2. 核心功能模块

### 2.1 工程管理 (Project Management)
- **卡片式首页**：以网格形式展示历史工程，显示路径、最后修改时间及素材统计。
- **自动扫描**：创建工程时，自动递归扫描指定目录下的视频与音频文件。
- **持久化存储**：记录工程配置与文件关联状态。

### 2.2 剪辑工作台 (Clip Workbench)
- **非编风格 UI**：模仿 DaVinci Resolve 的专业布局。
- **多轨道时间轴**：
    - **视频轨道 (Video Track)**：支持缩放（Zoom）的**连续缩略图序列 (Filmstrip)** 显示。
    - **视频字幕轨道**：显示导入的 SRT 字幕块。
    - **音频轨道 (Audio Track)**：支持缩放的**高保真波形图 (Waveform)** 显示，支持左右拖拽偏移。
    - **音频字幕轨道**：显示导入的 SRT 字幕块，随音频轨道同步移动。
- **智能对齐 (Auto-Sync)**：
    - 输入对白关键词（如“你叫什么名字”）。
    - 系统自动计算视频字幕与音频字幕的时间差。
    - 自动调整音频轨道偏移量，实现声画对齐。
- **实时预览**：
    - 空格键播放/暂停。
    - 画面左上角半透明叠加：`源文件名 | Source TC | Record TC`。

### 2.3 全局检索中心 (Global Search)
- **跨库检索**：对所有已入库工程的 SQLite 数据库进行模糊查询。
- **双行结果展示**：
    - **Row 1 (Video)**：视频文件名、匹配字幕（高亮）、时间码、**[复制路径]**、**[打开文件夹]**。
    - **Row 2 (Audio)**：音频文件名、原始/对齐时间码、**[复制路径]**、**[打开文件夹]**。
- **深度联动**：双击搜索结果 -> 跳转至剪辑页 -> 自动定位并播放。

## 3. 技术架构

### 3.1 技术栈
- **框架**：Flutter Windows Desktop
- **视频播放**：`media_kit` (基于 libmpv，高性能，支持多实例)
- **数据库**：`sqflite_common_ffi` (SQLite)
- **文件处理**：`ffmpeg_kit_flutter` (或调用本地 FFmpeg 命令行) 用于提取缩略图与波形数据。
- **UI 组件库**：Material 3 / Fluent UI

### 3.2 数据库设计 (ER Model)
```sql
-- 媒体关联表：记录声画对齐关系
CREATE TABLE media_relations (
    id INTEGER PRIMARY KEY,
    project_path TEXT,
    video_path TEXT,      -- 视频绝对路径
    audio_path TEXT,      -- 音频绝对路径
    sync_offset_ms INTEGER, -- 音频相对于视频的偏移量 (毫秒)
    created_at INTEGER
);

-- 字幕表：存储核心检索数据
CREATE TABLE subtitles (
    id INTEGER PRIMARY KEY,
    relation_id INTEGER,  -- 关联 ID
    content TEXT,         -- 字幕内容
    
    -- 统一时间轴时间 (用于播放跳转)
    timeline_start_ms INTEGER,
    timeline_end_ms INTEGER,
    
    -- 原始文件信息 (用于回溯)
    original_video_tc_start TEXT,
    original_audio_tc_start TEXT,
    
    FOREIGN KEY(relation_id) REFERENCES media_relations(id)
);
```

## 4. 关键技术实现细节

### 4.1 视频缩略图序列 (Filmstrip)
- **方案**：根据当前时间轴的缩放比例（Pixels per Second），计算需要提取的关键帧数量。
- **优化**：使用后台 Isolate 或 FFmpeg 命令行批量提取低分辨率图片（如 160px 高度），缓存至临时目录，按需懒加载。

### 4.2 音频波形渲染 (Waveform)
- **方案**：导入音频时，后台运行 FFmpeg 命令 `ffmpeg -i input.wav -ac 1 -filter:a aresample=8000 -map 0:a -c:a pcm_s16le -f data -` 获取降采样后的 PCM 数据。
- **绘制**：使用 `CustomPainter` 根据 PCM 数据绘制振幅包络线。
- **性能**：对长音频数据进行分块（Chunking），仅绘制可视区域内的波形。

### 4.3 智能对齐算法
1.  **输入**：关键词 $K$，视频字幕集合 $S_v$，音频字幕集合 $S_a$。
2.  **查找**：
    - 在 $S_v$ 中找到包含 $K$ 的字幕 $s_{v,i}$，记录开始时间 $t_{v,start}$。
    - 在 $S_a$ 中找到包含 $K$ 的字幕 $s_{a,j}$，记录开始时间 $t_{a,start}$。
3.  **计算**：偏移量 $\Delta = t_{v,start} - t_{a,start}$。
4.  **应用**：音频轨道整体平移 $\Delta$ 毫秒。

## 5. 开发阶段规划
1.  **Phase 1**: 项目初始化、左侧导航框架、首页工程管理 UI。
2.  **Phase 2**: **核心时间轴 UI 开发**（视频缩略图+音频波形）。
3.  **Phase 3**: 多媒体加载与多轨道逻辑实现。
4.  **Phase 4**: 字幕导入解析与“一键对齐”功能。
5.  **Phase 5**: 数据库存储与全局检索功能。
6.  **Phase 6**: 细节打磨（快捷键、状态栏、性能优化）。
